# Web logs
Web logs allow you to see different events happening inside your guild. Some of these events let you know about setup issues with Monni and what goes on your server, like simpukka executions. All the information except timestamp and category is stored encrypted. This means no unauthorized party can access the information. Guild ID is stored hashed to provide an extra layer of security by making it harder to figure out which guild log belongs to.

:::info
Web logs are stored for 2 weeks, after which they are deleted. If the limit of 2000 web logs is reached, the oldest 100 web logs will be deleted to make space. For premium guilds the limits is 10000 web logs.
:::
