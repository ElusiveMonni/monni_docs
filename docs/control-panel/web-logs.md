# Web logs
*This page is based on the old version of the site, which can be found at https://old.monni.fyi/*

Web logs allow you to see different events happening inside your guild. Some of these events let you know about setup issues with Monni and what goes on your server, like simpukka executions. 

All the information except for timestamp and category is stored and encrypted. This means no unauthorized party can access the information. Guild ID is stored and hashed to provide an extra layer of security by making it harder to figure out which guild log it belongs to.

:::info
Web logs are stored for 2 weeks, after which they are deleted. If the limit of 2000 web logs is reached, the oldest 100 web logs will be deleted to make space. For premium guilds the limits is 10,000 web logs.
:::
