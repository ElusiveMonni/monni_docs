# Heartbeat command

A command for identifying potential issues while also attempting to automatically fix them.

:::slash
**heart-beat** is a [slash command](/commands/info/slash/)!
:::

:::ephemeral
**Heartbeat** is a [ephemeral command](/commands/info/ephemeral)!
:::

:::admin
**Heartbeat** is an [administrator command](/commands/info/admin)!
:::

### Arguments

This command takes no arguments.

## 🔒 Required permissions

Ensure Monni has the following permissions.  
`Guild Manage`
