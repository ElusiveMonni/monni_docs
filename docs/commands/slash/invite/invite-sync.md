# Invite Sync

A command for syncing invites between the bot and the guild. If the bot fails to track what invites have been used, running this can fix the issue.

:::slash
**Invite Sync** is a [slash command](/commands/info/slash/)!
:::

:::ephemeral
**Invite Sync** is a [ephemeral command](/commands/info/ephemeral)!
:::

:::admin
**Invite Sync** is an [administrator command](/commands/info/admin)!
:::

## Arguments

This Command takes no arguments.

## 🔒 Required permissions

Ensure Monni has the following permissions.  
`Manage Guild`
