# Mod | Edit Case

Lets you edit the reason or duration of a moderation case using a case ID as input. You can choose to let the member know about the change.

---
## Arguments

- **1 Case_id**
    The ID of the case you'd like to edit, like `H4MR9T`. You can find these in the history command, your logs or the dashboard.
