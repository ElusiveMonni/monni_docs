# Verified account

A command for displaying the account a member verified with, like their Roblox or Minecraft account.

> If the user hasn’t verified with their account yet, by default the command will return Discord account information.

:::slash
**Verified account** is a [slash command](/commands/info/slash/)!
:::

You can also right click a member and choose **Apps** then **Verified account**.

---
## Arguments

- 1 **member:**  
    Member whose information will be displayed. Takes Discord name or ID.

## 🔒 Required permissions

No permissions required.
