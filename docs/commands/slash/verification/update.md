# Update Command

A command for updating the nickname of a server member. The nickname is based on the nickname setting of the [**Verification module**](/modules/verification).

:::slash
**Update** is a [slash command](/commands/info/slash/)!
:::

You can also right click a member and choose **Apps** then **Update**.

---
## Arguments

- 1 **Member**  
    Member of the server whose nickname should be updated. Takes Discord name or ID.

## 🔒 Required permissions

Ensure Monni has following permissions.  
`Manage Nicknames`

> Make sure Monni’s role is [above](/guides/monni-role-position) the roles of the members whose nicknames you want it to change.
