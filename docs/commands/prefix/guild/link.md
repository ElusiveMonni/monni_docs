# Link command

Links the channel you run it in to Monni, so it can be picked in the dashboard. This is how you use threads, forum posts and other channels that don't show up in the dashboard's channel list. Read more about [linked channels](/general-settings/linked-channels).

:::info
**link** is a [prefix command](/commands/prefix/)!
:::

---
## Usage

`@Monni link <code>`

## Arguments

- 1 **Code**  
    The code shown in the dashboard after you choose `Channel not listed...` in a channel picker.

## 🔒 Required permissions

You need the **Manage Server** permission to link a channel.
