Our ANSI coloured text generator can be used to write and create the coloured format for Discord text. To get started:
1. Write your message.
2. Highlight the text section you'd like to change.
3. Select the text colour (FG), background (BG), and formatting. (Like bold from the top.)
4. Once done, press copy and paste it into discord.
