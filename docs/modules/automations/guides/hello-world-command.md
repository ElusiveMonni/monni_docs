Lets start with a classic hello world example.
1.  create a message trigger with prefix of `!hello`. This way the bot knows to responds to messages starting with `!hello`
2. Then add `Send text message` action and set message as `Hello World`.
3. Bot will now respond `Hello World` when `!hello` is sent.
