---
title: Mass actions
description: "Run actions on many members at once with the For each member action, like giving everyone with a role a new role."
---
Mass actions refers to a special type of action called **for each member**. It lets you run actions on multiple people at once based on criteria provided with conditionals. If the conditional is true for the member then it will run the defined actions. This makes it easy to run simple and complex operations like giving a role to everyone hence the name mass actions. 

![For each member action with a limit of 500 members, filters and the actions to run](assets/for-each-member.png)

:::danger
Leaving conditionals empty means it will apply to everyone.
:::

## Limits
**For each member action**, it is limited to affect 500 members and 10000 with premium.

:::info
Due to an abuse risk, by default limits are strict. If you have a use case where the limits are too low, please get [in touch](https://monni.fyi/support) and we can increase them.
:::
